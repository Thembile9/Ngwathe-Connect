# Account upgrade
Back up the database and test on a separate Supabase project first. Apply the new migration using the SQL editor or your normal migration workflow. Do not rerun old migrations on an existing database. Verify existing staff roles and provision the first administrator through a trusted database administrator, not public registration. Existing complaints have no owner and must be linked only after verifying ownership. Existing WhatsApp database history is retained; disable the external webhook in Meta separately. Use the existing local .env, never commit it. Run npm ci, npm run check:structure, npm run typecheck, npm run build and npm run dev. Test anonymous redirects, resident registration, staff role routing, two residents with different reports, complaint creation and staff updates. Existing sessions remain signed in until sign-out. Messaging, push notifications and production security review are not implemented in this increment.
